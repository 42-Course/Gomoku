Module move_ordering 

Source
Expand description

Move ordering heuristics for negamax alpha-beta search.

Candidate moves are scored before expansion to improve alpha-beta pruning efficiency and reduce the explored search tree.

Current ordering heuristics include:

  • transposition-table best move
  • immediate winning moves
  • captures
  • local tactical threats
  • center proximity
