Module search

Expand description

Negamax + alpha-beta search with transposition table support.

§Conventions

  • Scores are from the side-to-move’s perspective (negamax).
  • Terminal wins return -(WIN_SCORE + depth) so faster mates outrank slower ones.
  • The search uses make/unmake on a single Game; on return the game is in exactly the state it was on entry.

§Examples

ⓘ
let mut game = Game::new();
let mut tt = TranspositionTable::new(20);
let result = best_move(&mut game, 4, &mut tt);
if let Some((x, y)) = result.best_move {
    game.play_move(x, y).unwrap();
}

Constants§

WIN_SCORE
Score returned for a decisive terminal position. Large enough to dominate any heuristic evaluation, small enough that score + depth can’t overflow.

Functions§

Run alpha-beta and return the best move + score.
negamax 🔒
Negamax with alpha-beta pruning and transposition table support.
terminal_score 🔒
If the position is terminal, return its score from the side-to-move’s perspective. A player can never be on-move in a position they already won, so any Win(_) encountered here is a loss for the side to move.
