pub fn pack_line( &self, x0: isize, y0: isize, dx: isize, dy: isize, max_len: u32, player: Player, ) -> (u32, u32, u32)

Pack one straight line of cells into two bitmasks.

Walks from (x0, y0) along (dx, dy) for at most max_len steps, stopping at the board edge. Returns (me, opp, len) where:

  • bit i of me is set when the i-th cell holds player,
  • bit i of opp is set when it holds the opponent,
  • len is the number of cells actually visited.

len <= 19 < 32, so a u32 is always wide enough.

Cells beyond the line (off-board, or past len) sit at zero in both masks - pattern matchers that need an empty cell at an endpoint won’t see them as empty, so the board edge is a wall.

§Examples
ⓘ
// Pack the row containing y = 9 from left to right, for Black.
let (me, opp, len) = board.pack_line(0, 9, 1, 0, BOARD_SIZE as u32, Player::Black);

pub fn for_each_line<F>(&self, player: Player, min_len: u32, f: F)
where F: FnMut(u32, u32, u32),

Visit every distinct horizontal/vertical/diagonal/anti-diagonal line on the board for player, calling f(me, opp, len) for each.

Each line is packed via Board::pack_line. Lines shorter than min_len are skipped (no useful pattern fits in fewer cells, and skipping cuts the diagonal count almost in half).

§Coverage
  • All BOARD_SIZE rows and BOARD_SIZE columns.
  • Both diagonal families, starting from cells where the previous cell is off-board.
§Examples
ⓘ
let mut totals = PatternCounts::default();
board.for_each_line(Player::Black, 5, |me, opp, len| {
    totals.add(&count_patterns(me, opp, len));
});
